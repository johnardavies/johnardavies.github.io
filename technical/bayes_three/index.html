1. First principles evaluation based on Bayes’ formula: Bayesian factors#

The Bayesian framework has a direct way to evaluate models. Using Bayes’ formula gives an expression for the probability of a model given the data: If we have two Models: Model 1 and Model 2 then the relative probability of the models given the data is a ratio known as a Bayesian factor. If there is no reason to favour any model in terms of the prior of the different modelling approaches being correct, then the prior probabilities of both models are equal and the factor becomes the ratio of the two models’ likelihoods. If the ratio is greater than 1 this favours choosing Model 1 (and vice versa). To go from these very general conditions to calculating probabilities we use the Bayesian equation for the posterior i.e. the probability of a model’s parameters ($\theta$) given the data and its structure (M): In finding the optimal parameters the marginal likelihood (also sometimes referred to as the evidence) is just a normalisation factor which does not affect the maximum of the posterior. However, here it gives the probability of the data given the model and the uncertainty in its parameters which is what is needed to calculate Bayesian factors. We average the likelihood over the prior distributions of the model’s parameters to obtain the probability of the data given the model. We can therefore calculate and compare the marginal likelihoods of different models to evaluate them.

A simple analytical example of this

There is some noisy data on a variable where:

• Model 1: one person asserts the variable’s true underlying value is zero

• Model 2: another person’s view is that the data is better modelled by a parameter lambda ($\lambda$) estimated from the data

We assume that in Model 2 there is a prior that is uniform between $\lambda_{\min}$ and $\lambda_{\max}$. The likelihood function for the parameter is assumed to have a maximum at $\lambda_0$ and a variance of $\delta \lambda^2$. The broader the prior i.e. $\lambda_{\max}$-$\lambda_{\min}$ relative to the variance in the data $\delta \lambda \sqrt{2\pi}$ the higher is the Occam factor.

2. The analytical approximation: The Bayesian Information Criteria (BIC)#

In practical terms a direct analytical solution to calculate the marginal likelihood for model comparison given the data will typically not be possible as it was in the previous example. One approach is to estimate the marginal likelihood integral by calculating it using Markov Chain Monte Carlo. Another is to use a metric that approximates the marginal likelihood, but which is easier to compute. 3. Adapting cross-validation to a Bayesian context: Pareto Smooth Importance Sampling Leave One Out (PSIS-LOO) cross-validation#

In the previous section the model evaluation took Bayes’ formula as its starting point. Another strategy is to go in the other direction and adapt standard model evaluation techniques to a Bayesian context. The PSIS-LOO metric is an application of cross-validation to evaluating Bayesian models.

One reason to take this approach, rather than the Bayesian factor methodology and approximations to it described previously, is that intuitively model evaluation should be about how well the model performs the task we are interested in, for example, its forecasting performance. The marginal likelihood is a theoretically elegant measure of how well a model explains the data, but it is not typically what one directly cares about in using a model. It is also highly sensitive to the choice of priors as the first example showed. The relative preference for Model 2 relative to Model 1 in the first example depended directly on the width of the prior which can be highly subjective.

We examine the different components of PSIS-LOO in turn:

3.1 Leave One Out (LOO) cross-validation

In cross-validation we partition the data into N groups, randomly select a hold-out group and then train a model on the remaining data assessing its performance on the hold-out group. We do this multiple times and then average the results of the chosen error metric across the hold out groups as a measure of the model’s predictive performance. This has the advantage over a single test and training data set that it maximises the data the model is estimated on reducing the risk of bias. The estimate of the error rate is also likely to be less variable than with a single test/training split.

In Leave One Out cross-validation we drop one set of observations from the sample (i.e. a value of the dependent variable and its associated independent variables) and estimate the model on the remaining datapoints. We then do this for all the n data points in the sample and average the resulting error metric.

Leave One Out cross-validation is considered to have a lower level of bias than K-fold validation as each model is estimated on N -1 observations (where N is the sample size). However, K-fold cross-validation is faster to estimate as the model is estimated K times (typically 5 or 10) as opposed to N times for Leave One Out cross-validation. The K-fold cross-validation estimate of the errors is considered to have lower variance than leave one out cross-validation as many of the model runs will be more highly correlated as the data in them is very similar increasing the variance of the errors estimator. The basis for the 5 or 10 fold cross-validation measure is that these values of K have been found to optimise for low levels of bias and variance.

Bayesian Leave One Out cross-validation

In the case of a Bayesian model we calculate the probability of data point $y_i$ when it and its associated explanatory variables are dropped from the data the model is estimated on. We do this for all the n data points and then log the joint product of the probabilities giving a sum of the expected log predicted density from LOO (elpd).

The logged individual terms in the sum are the probabilities of the associated omitted observation $y_i$ given theta, where the theta has the posterior distribution calculated excluding $y_i$ (represented by $y_{-i}$) i.e.

In practice the posterior distribution, as it cannot be calculated analytically, is estimated by S simulation draws that we have obtained from the prior distributions. As Bayesian model estimation usually involves simulation it is not practically feasible to estimate the model n times across all data points as this would take a long time. Importance sampling is used to address this.

3.2 Importance sampling

In weighting the likelihood of data point i by the posterior distribution of theta excluding point i we are weighting a function by a probability distribution p(x). In general terms:

If we do not know the distribution for p(x) (as we do know the posterior distribution for theta excluding i) we can use another probability distribution that we know, say q(x), to rewrite the expectation in terms of the probabilities q(x) applied to the function weighted by the ratio of the p and q distributions.

This can be used to simplify the problem. In our specific use case:

We do not know the posterior distribution of theta if we drop data point i (or at least it would be a lot of work to find it N times for each data point), but we will estimate the posterior distribution of theta from the model simulation.

If we weight the draws from the posterior distribution of theta omitting $y_i$ by the ratio of the posterior distribution of theta without $y_i$ to the full posterior distribution of theta then the resulting term simplifies to one proportional to the inverse of the likelihood of $y_i$ (which we can obtain from the simulation). It is proportional as both the top and bottom of the fraction have different normalisation terms in terms of their integrals with respect to theta.

These weights simplify the calculation of the hold out probability. Which we can then apply to calculate the probability of a data point $y_i$ dropping that point and the information associated with it in the sample. For our S draws of theta values to estimate the posterior we calculate the probability of the predicted y (y tilde) given a draw s from theta $p(\tilde{y} \mid \theta^{(s)})$. When the probability of $y_i$ is higher the weight is lower.

The posterior distribution simulation used to estimate the model will naturally generate estimates of the posteriors of the parameters and estimates of the likelihood at a given point. This means that rather than running one regression per data point we can run our usual posterior simulation and then use the importance sampling to reweight it to approximate the effects of leaving out individual data points. Where our reweighting distribution differs from the original distribution this process can for specific data points generate very large weights for small likelihood values making the outcome instable. Pareto smoothing is used to reduce this volatility.

3.3 Pareto smoothing

To address the large weights the original PSIS-LOO paper recommends taking the largest 20% importance ratios $r_i$ and fitting a Pareto distribution to them and using the fitted values rather than the original numbers. Using the modelled numbers reduces the large weights making the computed metrics more stable and we replace the original weights ($r_i$) with the smoothed weights ($w_i$).

For each data point the resulting shape parameter (k) of the fitted Pareto distribution is calculated. In the original paper it was found that

• If k < $\frac{1}{2}$ then the estimated distribution converges
• If $\frac{1}{2} \geq k \leq 1$ the variance of the importance ratios can be infinite and distributions will converge more slowly. The authors report that good performance was found in k values up to 0.75
• If k > 1 the mean and variance of the weights do not exist and the distribution will not produce robust results What the output from the metric looks like from PyMC

import matplotlib.pyplot as plt
import numpy as np
from scipy.stats import gamma as gammadist
from scipy.optimize import minimize

fig, ax = plt.subplots(1, figsize=(12, 15))

# The x values we are working over
x = np.arange(0, 2, 0.01)

# The function we are approximating with Laplace's method
def f(x):
    return gammadist.pdf(x, 2, loc=0, scale=1 / 5)


def maximum_finder(func_to_max):
    """Get the maxmium value of the function"""

    # Provide an initial guess x0
    x0 = [1]

    def minimiser(f):
        return lambda x: -f(x)

    arg_val = minimiser(func_to_max)

    # Run minimize
    res = minimize(arg_val, x0)

    # Extract the maximum value and location
    max_x = res.x[0]

    return max_x

# Get the location of the maximum of the function
max_loc = maximum_finder(f)


def laplace_variance_from_curvature(func, x0, eps=1e-4):
    """Estimate Laplace variance as the inverse of the second derivative of log f at the maximum."""
    second_derivative = (
        np.log(func(x0 + eps))
        - 2 * np.log(func(x0))
        + np.log(func(x0 - eps))
    ) / (eps**2)
    return -1 / second_derivative

# Get the estimate variance from the curvature at the maximum
laplace_variance = laplace_variance_from_curvature(f, max_loc)


def laplace_approx(x, max_point, var_orig_dist):
    """The Laplace approximation to a gamma function"""
    peak_height = gammadist.pdf(max_point, 2, loc=0, scale=1 / 5)
    return peak_height * np.exp(-((x - max_point) ** 2) / (2 * var_orig_dist))
    


fig, ax = plt.subplots(figsize=(9, 6), dpi=150)

ax.plot(

    color="blue",

)

ax.plot(

    laplace_approx(x, max_loc, laplace_variance),
